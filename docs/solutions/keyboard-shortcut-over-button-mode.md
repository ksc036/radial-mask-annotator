# Keyboard Shortcut Over Button Mode

## Context

The radial polygon app briefly added visible plus/minus buttons for point nudging. The intended interaction was keyboard-based: `[` moves the selected point inward and `]` moves it outward.

## Rule

When a user asks to switch from a button interaction to a keyboard interaction, remove or hide the prior button affordance unless they explicitly ask to keep both. Keeping both can make the UI look like the requested feature was not implemented.
